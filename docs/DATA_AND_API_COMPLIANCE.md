# Data and API Compliance

This repository distributes source code and small synthetic example inputs only.

It does not distribute:

- private agricultural field boundaries;
- production road datasets;
- Google Street View imagery;
- Google metadata responses collected for production;
- API credentials;
- generated research datasets.

Users are responsible for confirming that they have the right to use each field-boundary dataset,
road dataset, and third-party service. Google Street View imagery and metadata remain subject to
Google Maps Platform terms, billing, attribution, storage, and display requirements. OpenStreetMap
data and derivatives remain subject to the Open Database License and applicable attribution rules.
