# Portfolio Narrative

AgriView demonstrates applied geospatial software engineering for agricultural imagery acquisition.

## Technical strengths

- spatial integration of field polygons and road networks;
- geometry-aware candidate sampling;
- field-facing heading estimation;
- metadata-first API design;
- configurable seasonal image filtering;
- separate field-centric and points-only workflows;
- reproducible folder organization and logging;
- secure environment-variable credential handling.

## Accurate positioning

AgriView acquires and organizes imagery that may support later annotation, crop-recognition, and
computer-vision work. Crop classification and agronomic diagnosis are not implemented in the
current repository.
